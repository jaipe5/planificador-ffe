# Planificador de prácticas FFE

Versión original del 28 de octubre de 2026. Herramienta de cálculo de fechas de prácticas FFE para Formación Profesional.

## Uso
Abre `index.html` o publica estos archivos juntos con GitHub Pages. El motor funciona en el navegador y guarda configuraciones en `localStorage`.

## Referencia
Inicio: 16/02/2027, objetivo: 500 horas, lunes a viernes con calendario precargado.

- 8 horas diarias: 24/05/2027 (última jornada de 4 h)
- 7 horas diarias: 04/06/2027 (última jornada de 3 h)
- 6 horas diarias: 01/07/2027 (última jornada de 2 h)

Para ejecutar las comprobaciones (requiere Node.js): `node check.cjs`.

**Advertencia:** el calendario precargado es una referencia docente, no una validación oficial de festivos o periodos autorizados. Ver `LEEME.txt` para instrucciones y limitaciones.
